Architecture recommendation

Retain the existing Next.js/TypeScript application and PostgreSQL. Deliver one conversational assistant through the ServiceM8 Hosted Add-on. Use OpenAI Responses function calling, a trusted application tool gateway and small, approved capability increments. Introduce background scheduling after the read-only experience is proven. ServiceM8 stays the job record.

The four workflow sections preserve the business path and loopbacks; cross-section arrows are labelled as continuation points. The management view proposes AD reporting across the workflow; AD is unconnected in the original source. AA should include the next action and owner as well as the next booking.
